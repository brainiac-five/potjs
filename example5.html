POT JS Example 5: Network

	Check source.


	This page connects to a local Swarm network.

	It is for illustration but can be made to run.

	As is, it will error because the batch id hardcoded below
	will not work and the swarm network might not be running.

	To test it, start the local network with `make locnet_start`,
	create a batch with `make locnet_batch`, copy the batch id
	from file `.batch_id` into this page. Or, checkout example 6.
